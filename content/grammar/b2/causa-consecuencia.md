## Cause

| | |
|---|---|
| **porque** | the everyday one; the only one used freely in speech |
| **ya que** / **puesto que** | a cause the listener already knows |
| **dado que** | colder, written, typical of reports |
| **como** | always sentence-initial |
| **por** + noun/infinitive | `por miedo`, `por no llegar tarde` |

The `porque` / `puesto que` distinction is worth having. **`porque` can introduce new
information**; `puesto que` and `ya que` present something already shared:

- `No fui **porque** estaba enfermo.` — you did not know
- `**Puesto que** estamos todos, empezamos.` — everyone can see it

## Consequence

| | |
|---|---|
| **así que** | spoken |
| **por eso** | neutral |
| **por lo tanto** / **por consiguiente** | formal |
| **de ahí que** | formal, **+ subjunctive** |

## de ahí que and its subjunctive

This one breaks the pattern you have spent ten units learning:

> `Llegó tarde, **de ahí que** se **perdiera** la primera parte.`

He definitely missed it. Nobody is doubting anything. The subjunctive appears **because the
construction demands it**, not because of any uncertainty.

It is a frozen expression — a piece of grammar that stopped obeying the system and kept its old
form. Spanish has a handful of these, and the honest advice is to memorise them rather than
look for the logic.

## por and porque

Easily confused in writing:

| | |
|---|---|
| **porque** | because — introduces a clause |
| **por qué** | why — a question |
| **por que** | for which — rare |
| **porqué** | the reason — a noun: `el porqué de todo` |

Only the first two matter in practice, and the accent is the whole difference.

## Watch out

`Como` meaning "since" must open the sentence. `Me fui como no contestabas` is wrong — it would
have to be `Me fui porque no contestabas` or `Como no contestabas, me fui`.
