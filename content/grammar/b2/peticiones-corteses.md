Politeness in Spanish works by **distance from the present**. The further from a plain present
indicative you go, the more courteous you sound.

| | |
|---|---|
| `**Quiero** una cita.` | correct, and sounds like an order |
| `**Querría** una cita.` | conditional — pleasant |
| `**Quisiera** una cita.` | imperfect subjunctive — the standard polite form |
| `¿**Podría** darme una cita?` | conditional + a question — politest |

Two mechanisms are stacking here: shifting the tense, and turning a statement into a question.
A question hands the other person the choice, which is what politeness is.

## quisiera is not hypothetical

`Quisiera` looks like a second conditional missing its `si`, but it carries no hypothetical
meaning at all. It simply means `quiero`, said carefully. Treat it as a fixed formula.

The same goes for `¿Sería tan amable de...?` and `¿Le importaría...?`

## Softening in other ways

| | |
|---|---|
| `**A ver si** puedes ayudarme.` | let's see if — very common, very soft |
| `¿**Te importa** si...?` | do you mind if |
| `**Quería** preguntarte una cosa.` | imperfect for a present request — instantly softer |

That last one is worth noticing: the plain imperfect indicative also works as a politeness
device. `Quería pedirte un favor` is standard, and slightly warmer than `quisiera`.

## Register goes with it

Polite requests usually travel with `usted` (Unit 10), and the two reinforce each other. With
`tú` the conditional alone is normally enough: `¿Podrías ayudarme?`

## Watch out

Spanish does not use `por favor` as heavily as English uses "please". Over-inserting it sounds
oddly pleading. The politeness is carried by the verb form, not by an added word — which is
exactly why this construction is worth learning properly.
