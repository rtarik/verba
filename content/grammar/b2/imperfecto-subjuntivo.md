The mood of what is **not the case**: impossible wishes, hypotheticals, and polite distance.

## How to build it

Take the **third person plural of the preterite**, drop `-ron`, add `-ra`.

| infinitive | ellos preterite | imperfect subjunctive |
|---|---|---|
| hablar | habla**ron** | habla**ra** |
| comer | comie**ron** | comie**ra** |
| tener | tuvie**ron** | tuvie**ra** |
| hacer | hicie**ron** | hicie**ra** |
| ser / ir | fue**ron** | fue**ra** |
| decir | dije**ron** | dije**ra** |
| poder | pudie**ron** | pudie**ra** |

This is the one place where the preterite irregulars pay you back: learn them once in A2 and they
carry straight through. There are **no separate irregulars** in this tense.

| | |
|---|---|
| yo | tuvie**ra** |
| tú | tuvie**ras** |
| él / ella | tuvie**ra** |
| nosotros | tuvi**é**ramos |
| ellos | tuvie**ran** |

Only `nosotros` takes an accent, and it lands on the syllable before the ending.

## The -se forms

Every one of these has a twin: `tuviese`, `hiciese`, `fuese`, `dijese`. They mean **exactly** the
same thing. In Spain both are used and `-se` sounds slightly more formal or literary; in Latin
America `-ra` dominates. Pick one and stay consistent.

## Where it appears

- **Second conditional** — `Si tuviera tiempo, iría.` See [si + imperfect subjunctive](segunda-condicional).
- **After a past main verb** — `Quería que vinieras.` See [sequence of tenses](correlacion-de-tiempos).
- **como si** — always, whatever the main tense: `Habla como si estuviera aquí.`
- **ojalá, for impossible wishes** — `Ojalá lloviera.` (it won't)
- **Politeness** — `Quisiera una cita.` See [polite requests](peticiones-corteses).

## Watch out

`Ojalá llueva` and `ojalá lloviera` are both correct and differ in hope. The present subjunctive
treats the wish as possible; the imperfect concedes that it is not. The grammar carries the
resignation.
