Spanish has a construction that turns an accident into something that happened *to* you, rather
than something you did.

> `**Se me olvidó** el informe.` — I forgot the report.

Literally: *the report forgot itself to me*. Nobody is at fault, least of all the speaker.

## The pattern

**se** + indirect object pronoun + verb + **the thing**

| | |
|---|---|
| `**Se me** olvidó.` | I forgot |
| `**Se te** cayó.` | you dropped it |
| `**Se le** rompió.` | he broke it |
| `**Se nos** perdieron las llaves.` | we lost the keys |

The verb agrees with **the thing**, not with the person — exactly like `gustar`:

- `Se me olvid**ó** el informe.` — one report
- `Se me olvidar**on** los informes.` — several

## Why it matters

Compare the two ways of saying the same event:

| | |
|---|---|
| `**Rompí** el vaso.` | I broke the glass — I did it |
| `**Se me rompió** el vaso.` | the glass broke on me — it happened |

Both are correct. The second is overwhelmingly more common for genuine accidents, and choosing
the first suggests you are accepting blame.

This is not evasiveness so much as a grammatical distinction English lacks: Spanish separates
*doing* from *having something happen to you*, and accidents belong in the second category.

## The verbs that use it

Typically things that go wrong by themselves: **olvidar, caer, romper, perder, quemar, acabar,
ocurrir, estropear**.

`Se me ocurrió una idea` — an idea occurred to me. Same structure, no misfortune involved.

## Watch out

Word order is fixed: `se` first, then the person, then the verb. `Me se olvidó` is a well-known
non-standard form — you will hear it, and it is stigmatised.
