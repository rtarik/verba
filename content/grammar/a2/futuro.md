After the preterite, this tense is a gift. **The endings attach to the whole infinitive**, and
all three verb types take the same set.

| | hablar | comer | vivir |
|---|---|---|---|
| yo | hablar**é** | comer**é** | vivir**é** |
| tú | hablar**ás** | comer**ás** | vivir**ás** |
| él / ella | hablar**á** | comer**á** | vivir**á** |
| nosotros | hablar**emos** | comer**emos** | vivir**emos** |
| ellos | hablar**án** | comer**án** | vivir**án** |

Note there is no chopping off of `-ar` or `-er`. `hablar` + `é` = `hablaré`. Even `ser` behaves:
`ser` + `án` = `serán`.

Every ending carries an accent except `-emos`.

## The twelve irregular stems

They change the stem but keep exactly those endings. They fall into three tidy groups:

**Drop a vowel:**

| | |
|---|---|
| poder | **podr**é |
| querer | **querr**é |
| saber | **sabr**é |
| haber | **habr**á |

**Swap a vowel for d:**

| | |
|---|---|
| tener | **tendr**é |
| poner | **pondr**é |
| salir | **saldr**é |
| venir | **vendr**é |

**Their own thing:**

| | |
|---|---|
| hacer | **har**é |
| decir | **dir**é |

That is the complete list. Compare it with the preterite irregulars and you will notice these
are the *same verbs* — learn them once and they keep paying out.

## A second job: guessing

Spanish uses the future to speculate about the **present**, which surprises English speakers:

> `—¿Dónde está Pablo?`
> `—**Estará** en casa.` — He'll be at home. *(I assume)*

`¿Qué hora es? Serán las tres.` — it must be about three. Nothing about the future is involved;
it is a way of saying "probably".
