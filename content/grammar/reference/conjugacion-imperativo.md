The imperative is the only part of the system where the **affirmative and the negative are built
differently**. `Habla` means "speak"; "don't speak" is not *no habla* but **no hables** — a
different form entirely.

## The whole grid

| | affirmative | negative |
|---|---|---|
| tú | habl**a** | no habl**es** |
| usted | habl**e** | no habl**e** |
| nosotros | habl**emos** | no habl**emos** |
| vosotros | habl**ad** | no habl**éis** |
| ustedes | habl**en** | no habl**en** |

**Only the `tú` and `vosotros` rows differ between the columns.** Everything else is the present
subjunctive doing double duty, in both columns, unchanged.

## The three families

| | hablar | comer | vivir |
|---|---|---|---|
| tú | habla | come | vive |
| usted | hable | coma | viva |
| nosotros | hablemos | comamos | vivamos |
| vosotros | hablad | comed | vivid |
| ustedes | hablen | coman | vivan |

| | no hablar | no comer | no vivir |
|---|---|---|---|
| tú | no hables | no comas | no vivas |
| usted | no hable | no coma | no viva |
| nosotros | no hablemos | no comamos | no vivamos |
| vosotros | no habléis | no comáis | no viváis |
| ustedes | no hablen | no coman | no vivan |

## Where each form comes from

| form | source |
|---|---|
| **tú** affirmative | the `él` form of the present indicative — `habla`, `come`, `vive` |
| **vosotros** affirmative | the infinitive with `-r` swapped for `-d` — `hablad`, `comed`, `vivid` |
| everything else | the present subjunctive |

The `vosotros` rule is the most reliable in Spanish: **every verb, without exception**. `ir` →
`id`, `ser` → `sed`, `hacer` → `haced`, `decir` → `decid`, `poner` → `poned`, `irse` → `idos`.

## The eight irregular tú commands

Only the affirmative `tú` form is ever irregular. Learn these eight and there are no others.

| infinitive | tú | negative tú |
|---|---|---|
| decir | **di** | no digas |
| hacer | **haz** | no hagas |
| ir | **ve** | no vayas |
| poner | **pon** | no pongas |
| salir | **sal** | no salgas |
| ser | **sé** | no seas |
| tener | **ten** | no tengas |
| venir | **ven** | no vengas |

Notice the negatives are all perfectly regular subjunctives. The irregularity lives in one cell
each.

Two collisions worth knowing: **`ve`** is the `tú` command of both `ir` ("go") and `ver`
("look"), and **`sé`** is both the `tú` command of `ser` and the `yo` form of `saber`. Context
separates them without effort.

Compounds inherit: `componer` → **compón**, `mantener` → **mantén**, `detener` → **detén**,
`deshacer` → **deshaz**, `proponer` → **propón**, `contradecir` → **contradí**. They pick up a
written accent that the parent verb does not need.

## Irregular verbs across the whole grid

| | ser | ir | tener | hacer | decir | venir | poner | salir |
|---|---|---|---|---|---|---|---|---|
| tú | sé | ve | ten | haz | di | ven | pon | sal |
| usted | sea | vaya | tenga | haga | diga | venga | ponga | salga |
| nosotros | seamos | vamos | tengamos | hagamos | digamos | vengamos | pongamos | salgamos |
| vosotros | sed | id | tened | haced | decid | venid | poned | salid |
| ustedes | sean | vayan | tengan | hagan | digan | vengan | pongan | salgan |

| | no ser | no ir | no tener | no hacer | no decir |
|---|---|---|---|---|---|
| tú | no seas | no vayas | no tengas | no hagas | no digas |
| usted | no sea | no vaya | no tenga | no haga | no diga |
| nosotros | no seamos | no vayamos | no tengamos | no hagamos | no digamos |
| vosotros | no seáis | no vayáis | no tengáis | no hagáis | no digáis |
| ustedes | no sean | no vayan | no tengan | no hagan | no digan |

**`vamos` is the exception inside the exception.** "Let's go" is `vamos`, the indicative — not
`vayamos`. But the negative *is* subjunctive: `no vayamos`. `¡Vamos!` and `¡Vámonos!` are both
everyday; `vayamos` sounds like a sermon.

## Stem changes and spelling changes

Everything the present does, the imperative inherits.

| | pensar | volver | pedir | dormir | jugar |
|---|---|---|---|---|---|
| tú | p**ie**nsa | v**ue**lve | p**i**de | d**ue**rme | j**ue**ga |
| usted | p**ie**nse | v**ue**lva | p**i**da | d**ue**rma | j**ue**gue |
| nosotros | pensemos | volvamos | p**i**damos | d**u**rmamos | juguemos |
| vosotros | pensad | volved | pedid | dormid | jugad |
| ustedes | p**ie**nsen | v**ue**lvan | p**i**dan | d**ue**rman | j**ue**guen |

| | buscar | llegar | empezar | seguir | coger |
|---|---|---|---|---|---|
| tú | busca | llega | emp**ie**za | s**i**gue | coge |
| usted | bus**qu**e | lle**gu**e | **empiece** | s**i**ga | co**j**a |
| nosotros | bus**qu**emos | lle**gu**emos | empe**c**emos | s**i**gamos | co**j**amos |
| vosotros | buscad | llegad | empezad | seguid | coged |
| ustedes | bus**qu**en | lle**gu**en | **empiecen** | s**i**gan | co**j**an |

The two `tú`/`vosotros` rows come from the indicative and the infinitive, so they escape the
spelling changes; every subjunctive-derived row takes them.

## Where the pronouns go

**Affirmative: attached to the end, as one word.** **Negative: in front, as a separate word.**

| bare form | affirmative | negative |
|---|---|---|
| di | **dímelo** | **no me lo** digas |
| habla | **háblame** | **no me** hables |
| levanta | **levántate** | **no te** levantes |
| siente | **siéntese** | **no se** siente |
| da | **dáselo** | **no se lo** des |
| pongan | **pónganselo** | **no se lo** pongan |

Attaching a pronoun adds a syllable, which moves the stress — so an accent usually has to be
written in to hold it where it was:

| bare | + one pronoun | + two |
|---|---|---|
| habla | háblame | — |
| dime | — | dímelo |
| pon | ponlo | póntelo |
| trae | tráelo | tráemelo |
| escribe | escríbelo | escríbemelo |
| diga | dígame | dígamelo |
| compren | cómprenlo | cómprenmelo |

### Two spellings that break when a pronoun is added

**`nosotros` drops its final `-s` before `nos`:** `sentemos` + `nos` → **sentémonos**, not
*sentémosnos*. Also `vámonos`, `levantémonos`, `quedémonos`.

**`vosotros` drops its final `-d` before `os`:** `sentad` + `os` → **sentaos**, not *sentados*.
Also `levantaos`, `callaos`, `poneos`. The one exception is `ir`: **idos**, which keeps the `d`.

## Softer ways to tell someone what to do

The bare imperative is direct. In many situations Spanish reaches for something gentler:

| | |
|---|---|
| ¿**Puedes** cerrar la puerta? | Can you close the door? |
| ¿**Te importaría** cerrar la puerta? | Would you mind closing the door? |
| ¿**Me pasas** la sal? | Pass me the salt? (present as a request) |
| **A** callar. | Quiet, everyone. (`a` + infinitive, brisk) |
| **No** fumar. | No smoking. (infinitive on signs) |
| Se **ruega** no fumar. | Please do not smoke. (formal notice) |

See [polite requests](peticiones-corteses) for the register ladder in full.
