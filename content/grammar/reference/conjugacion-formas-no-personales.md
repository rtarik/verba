Three forms of a verb carry no person and no tense: the **infinitive** (`hablar`), the **gerund**
(`hablando`) and the **participle** (`hablado`). Two of them are the raw material for half the
tense system, so their irregular forms are worth knowing exactly.

## The gerund — *-ando* / *-iendo*

| family | ending | example |
|---|---|---|
| -ar | -**ando** | hablar → habl**ando** |
| -er | -**iendo** | comer → com**iendo** |
| -ir | -**iendo** | vivir → viv**iendo** |

| infinitive | gerund | | infinitive | gerund |
|---|---|---|---|---|
| trabajar | trabajando | | aprender | aprendiendo |
| estudiar | estudiando | | beber | bebiendo |
| cantar | cantando | | correr | corriendo |
| comprar | comprando | | escribir | escribiendo |
| llamar | llamando | | abrir | abriendo |
| esperar | esperando | | salir | saliendo |

### Stem changes: -ir verbs only

`-ir` verbs that change in the present change here too, `e→i` or `o→u`. `-ar` and `-er` verbs
never do.

| infinitive | gerund | | infinitive | gerund |
|---|---|---|---|---|
| pedir | p**i**diendo | | dormir | d**u**rmiendo |
| servir | s**i**rviendo | | morir | m**u**riendo |
| seguir | s**i**guiendo | | poder | p**u**diendo |
| repetir | rep**i**tiendo | | | |
| decir | d**i**ciendo | | | |
| venir | v**i**niendo | | | |
| sentir | s**i**ntiendo | | | |
| preferir | pref**i**riendo | | | |
| mentir | m**i**ntiendo | | | |
| vestir | v**i**stiendo | | | |
| reír | r**i**endo | | | |

Compare with the `-ar` and `-er` boot verbs, which keep their plain stem: `pensar` →
**pensando** (not *piensando*), `volver` → **volviendo** (not *vulviendo*), `contar` →
**contando**, `querer` → **queriendo**, `entender` → **entendiendo**, `jugar` → **jugando**.

The list above is not a coincidence: it is **exactly the same set of verbs** that change in the
third person of the [preterite](conjugacion-preterito). `pidió` / `pidiendo`, `durmió` /
`durmiendo`, `sintió` / `sintiendo`. One irregularity, two places.

### -iendo becomes -yendo after a vowel

When the stem ends in a vowel, `i` between vowels turns into `y`:

| infinitive | gerund | | infinitive | gerund |
|---|---|---|---|---|
| leer | le**y**endo | | construir | constru**y**endo |
| creer | cre**y**endo | | huir | hu**y**endo |
| caer | ca**y**endo | | destruir | destru**y**endo |
| traer | tra**y**endo | | incluir | inclu**y**endo |
| oír | o**y**endo | | ir | **yendo** |

`ir` → **yendo** is the odd one out: nothing is left of the infinitive but the `y`. It is also
rarely used, because "I am going" is normally just `voy`.

## The participle — *-ado* / *-ido*

| family | ending | example |
|---|---|---|
| -ar | -**ado** | hablar → habl**ado** |
| -er | -**ido** | comer → com**ido** |
| -ir | -**ido** | vivir → viv**ido** |

| infinitive | participle | | infinitive | participle |
|---|---|---|---|---|
| trabajar | trabajado | | tener | tenido |
| estudiar | estudiado | | saber | sabido |
| comprar | comprado | | poder | podido |
| llegar | llegado | | querer | querido |
| jugar | jugado | | vivir | vivido |
| pensar | pensado | | salir | salido |
| dormir | dormido | | pedir | pedido |
| estar | estado | | ser | sido |
| dar | dado | | ir | ido |

**Stem changes never reach the participle.** `poder` → **podido** (not *puedido*), `dormir` →
**dormido** (not *durmido*), `pedir` → **pedido**, `querer` → **querido**, `contar` →
**contado**. Whatever the gerund does, the participle does not copy it.

### An accent after a vowel

`-er`/`-ir` verbs whose stem ends in a vowel need an accent to keep the `i` a syllable of its
own:

| infinitive | participle |
|---|---|
| leer | le**í**do |
| creer | cre**í**do |
| caer | ca**í**do |
| traer | tra**í**do |
| oír | o**í**do |
| reír | re**í**do |

But not after `u`: `construir` → **construido**, `huir` → **huido**, `incluir` → **incluido** —
no accent, because `ui` is already a single syllable.

### The irregular participles — the complete list

| infinitive | participle | | infinitive | participle |
|---|---|---|---|---|
| abrir | **abierto** | | morir | **muerto** |
| cubrir | **cubierto** | | poner | **puesto** |
| descubrir | **descubierto** | | proponer | **propuesto** |
| decir | **dicho** | | suponer | **supuesto** |
| escribir | **escrito** | | componer | **compuesto** |
| describir | **descrito** | | resolver | **resuelto** |
| hacer | **hecho** | | romper | **roto** |
| deshacer | **deshecho** | | ver | **visto** |
| satisfacer | **satisfecho** | | prever | **previsto** |
| volver | **vuelto** | | ir | **ido** (regular) |
| devolver | **devuelto** | | | |
| envolver | **envuelto** | | | |

Almost the whole list ends in **-to** or **-cho**. Compounds inherit their parent's participle
without exception, so `componer` → `compuesto`, `deshacer` → `deshecho`, `descubrir` →
`descubierto` — you never have to learn those separately.

### The verbs with two participles

A few verbs have a regular participle for building tenses and an irregular one used as an
adjective. Using the wrong one is a real mistake, not a stylistic choice.

| infinitive | with haber | as an adjective |
|---|---|---|
| freír | ha freído | patatas **fritas** |
| imprimir | ha imprimido | un documento **impreso** |
| soltar | ha soltado | el perro está **suelto** |
| despertar | ha despertado | está **despierto** |
| elegir | ha elegido | el candidato **electo** |
| confundir | ha confundido | estoy **confuso** |

`He freído las patatas` — the action. `Unas patatas fritas` — the thing. `freído` and `frito`
are both accepted with `haber` in practice, but the adjective is always `frito`.

## The one thing to keep straight

After `haber`, the participle **never** changes for gender or number:

| | |
|---|---|
| Hemos **comido**. | not *comidos* |
| Ellas han **llegado**. | not *llegadas* |
| Las cartas que he **escrito**. | not *escritas* |

After `ser` or `estar`, it **always** agrees:

| | |
|---|---|
| Las cartas están **escritas**. | agrees with `cartas` |
| La puerta fue **cerrada**. | agrees with `puerta` |
| Los platos están **rotos**. | agrees with `platos` |

Same word, opposite rule, decided entirely by the verb in front of it.
