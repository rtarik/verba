Several hundred common verbs keep perfectly regular endings but change a vowel **in the middle**
when the stress falls on it. The change is a property of the individual verb — nothing in the
infinitive announces it — but once you know a verb changes, *where* it changes is completely
predictable.

## The four patterns

| pattern | model | yo | nosotros |
|---|---|---|---|
| **e → ie** | querer | qu**ie**ro | queremos |
| **o → ue** | poder | p**ue**do | podemos |
| **e → i** | pedir | p**i**do | pedimos |
| **u → ue** | jugar | j**ue**go | jugamos |

`u → ue` has exactly one member: **jugar**. The other three run to dozens of verbs each.

## The boot

The change hits four forms and skips `nosotros` and `vosotros`, because there the stress lands on
the ending instead of the stem. Drawn on the page, the four affected forms make a boot shape.

| | e → ie | o → ue | e → i | u → ue |
|---|---|---|---|---|
| yo | qu**ie**ro | p**ue**do | p**i**do | j**ue**go |
| tú | qu**ie**res | p**ue**des | p**i**des | j**ue**gas |
| él / Ud. | qu**ie**re | p**ue**de | p**i**de | j**ue**ga |
| **nosotros** | **queremos** | **podemos** | **pedimos** | **jugamos** |
| **vosotros** | **queréis** | **podéis** | **pedís** | **jugáis** |
| ellos / Uds. | qu**ie**ren | p**ue**den | p**i**den | j**ue**gan |

## Which tenses are affected

This is the part worth internalising: a stem change is not a present-tense fact. It reaches into
five places, and skips five others.

| tense | -ar / -er verbs | -ir verbs |
|---|---|---|
| **presente** | changes (boot) | changes (boot) |
| **presente de subjuntivo** | changes (boot) | changes (boot) **+ nosotros / vosotros** |
| **imperativo** | changes | changes |
| **gerundio** | no | **changes** (e→i, o→u) |
| **pretérito, 3rd person** | no | **changes** (e→i, o→u) |
| **imperfecto de subjuntivo** | no | **changes**, via the preterite |
| imperfecto | no | no |
| futuro | no | no |
| condicional | no | no |
| participio | no | no |
| infinitivo | no | no |

### The -ar / -er verbs: two places only

| | pensar | volver |
|---|---|---|
| presente | p**ie**nso, p**ie**nsas, p**ie**nsa, pensamos, pensáis, p**ie**nsan |  v**ue**lvo, v**ue**lves, v**ue**lve, volvemos, volvéis, v**ue**lven |
| pres. subj. | p**ie**nse, p**ie**nses, p**ie**nse, pensemos, penséis, p**ie**nsen | v**ue**lva, v**ue**lvas, v**ue**lva, volvamos, volváis, v**ue**lvan |
| imperativo | p**ie**nsa, p**ie**nse, pensemos, pensad, p**ie**nsen | v**ue**lve, v**ue**lva, volvamos, volved, v**ue**lvan |
| **pretérito** | pensé, pensaste, **pensó**, pensamos, pensasteis, **pensaron** | volví, volviste, **volvió**, volvimos, volvisteis, **volvieron** |
| **gerundio** | **pensando** | **volviendo** |
| **futuro** | **pensaré** | **volveré** |
| **participio** | **pensado** | **vuelto** (irregular for a different reason) |

### The -ir verbs: five places

`-ir` verbs carry a **second, weaker change** — `e→i` or `o→u` — into every form where the stem
is unstressed but followed by a stressed ending.

| | dormir (o→ue / u) | sentir (e→ie / i) | pedir (e→i / i) |
|---|---|---|---|
| presente | d**ue**rmo, d**ue**rmes, d**ue**rme, dormimos, dormís, d**ue**rmen | s**ie**nto, s**ie**ntes, s**ie**nte, sentimos, sentís, s**ie**nten | p**i**do, p**i**des, p**i**de, pedimos, pedís, p**i**den |
| pres. subj. | d**ue**rma, d**ue**rmas, d**ue**rma, d**u**rmamos, d**u**rmáis, d**ue**rman | s**ie**nta, s**ie**ntas, s**ie**nta, s**i**ntamos, s**i**ntáis, s**ie**ntan | p**i**da, p**i**das, p**i**da, p**i**damos, p**i**dáis, p**i**dan |
| pretérito | dormí, dormiste, d**u**rmió, dormimos, dormisteis, d**u**rmieron | sentí, sentiste, s**i**ntió, sentimos, sentisteis, s**i**ntieron | pedí, pediste, p**i**dió, pedimos, pedisteis, p**i**dieron |
| imp. subj. | d**u**rmiera… | s**i**ntiera… | p**i**diera… |
| gerundio | d**u**rmiendo | s**i**ntiendo | p**i**diendo |
| imperativo | d**ue**rme, d**ue**rma, d**u**rmamos, dormid, d**ue**rman | s**ie**nte, s**ie**nta, s**i**ntamos, sentid, s**ie**ntan | p**i**de, p**i**da, p**i**damos, pedid, p**i**dan |
| futuro | dormiré | sentiré | pediré |
| participio | dormido | sentido | pedido |

Read the `nosotros` cells down the subjunctive row: **durmamos, sintamos, pidamos**. That is the
one place the boot leaks, and it is `-ir` verbs only.

## How to tell whether a verb changes

You cannot, from the infinitive. These pairs settle the point:

| changes | does not change |
|---|---|
| **contar** → cuento | **cortar** → corto |
| **volver** → vuelvo | **volar**… also changes (vuelo) |
| **mostrar** → muestro | **montar** → monto |
| **pensar** → pienso | **pesar** → peso |
| **entender** → entiendo | **aprender** → aprendo |
| **encontrar** → encuentro | **entrar** → entro |
| **jugar** → juego | **juzgar** → juzgo |
| **sentar** → siento | **tratar** → trato |

There is no rule. The change is learned with the verb — which is why the yo form is the one to
memorise, since everything else in the boot follows from it.
