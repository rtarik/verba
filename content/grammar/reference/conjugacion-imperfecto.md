The easiest tense in Spanish. Two sets of endings, no stem changes anywhere, and **three
irregular verbs in the entire language**.

## The endings

| | -ar | -er / -ir |
|---|---|---|
| yo | -**aba** | -**ía** |
| tú | -**abas** | -**ías** |
| él / Ud. | -**aba** | -**ía** |
| nosotros | -**ábamos** | -**íamos** |
| vosotros | -**abais** | -**íais** |
| ellos / Uds. | -**aban** | -**ían** |

Every `-er`/`-ir` form carries an accent on the `í`, and the `-ar` family accents only
`-ábamos`. That single accent is the difference between `hablabamos` (not a word) and
`habl**á**bamos`.

`yo` and `él` are identical in this tense — `hablaba` is both "I used to speak" and "he used to
speak". When it is genuinely unclear, the pronoun goes back in: `yo hablaba`.

## Regular -ar verbs

| | hablar | trabajar | estar | jugar | pensar |
|---|---|---|---|---|---|
| yo | hablaba | trabajaba | estaba | jugaba | pensaba |
| tú | hablabas | trabajabas | estabas | jugabas | pensabas |
| él / Ud. | hablaba | trabajaba | estaba | jugaba | pensaba |
| nosotros | hablábamos | trabajábamos | estábamos | jugábamos | pensábamos |
| vosotros | hablabais | trabajabais | estabais | jugabais | pensabais |
| ellos / Uds. | hablaban | trabajaban | estaban | jugaban | pensaban |

`estar`, `jugar` and `pensar` are in that table on purpose. All three are irregular somewhere
else in the system — `estoy`, `juego`, `pienso`, `estuve` — and all three are perfectly regular
here. **Whatever a verb does elsewhere, it almost certainly does not do it in the imperfect.**

## Regular -er and -ir verbs

| | comer | tener | vivir | decir | hacer |
|---|---|---|---|---|---|
| yo | comía | tenía | vivía | decía | hacía |
| tú | comías | tenías | vivías | decías | hacías |
| él / Ud. | comía | tenía | vivía | decía | hacía |
| nosotros | comíamos | teníamos | vivíamos | decíamos | hacíamos |
| vosotros | comíais | teníais | vivíais | decíais | hacíais |
| ellos / Uds. | comían | tenían | vivían | decían | hacían |

Again, three of those five are heavily irregular verbs — `tengo`/`tuve`, `digo`/`dije`,
`hago`/`hice` — behaving impeccably.

More, in the yo form: `poder` → podía, `querer` → quería, `saber` → sabía, `poner` → ponía,
`salir` → salía, `venir` → venía, `traer` → traía, `conocer` → conocía, `dormir` → dormía,
`pedir` → pedía, `sentir` → sentía, `leer` → leía, `caer` → caía, `oír` → oía, `haber` → había,
`dar` → daba, `estar` → estaba.

## The three irregular verbs

| | ser | ir | ver |
|---|---|---|---|
| yo | **era** | **iba** | **veía** |
| tú | **eras** | **ibas** | **veías** |
| él / Ud. | **era** | **iba** | **veía** |
| nosotros | **éramos** | **íbamos** | **veíamos** |
| vosotros | **erais** | **ibais** | **veíais** |
| ellos / Uds. | **eran** | **iban** | **veían** |

That is the complete list. There is no fourth.

`ver` barely counts: its stem is `ve-` rather than `v-`, so it is really `ve` + the ordinary
`-ía` endings. `ser` and `ir` are the two that must simply be learned.

## Compounds built on it

The imperfect of `haber` is the auxiliary for the pluscuamperfecto — the tense for "had already
done it before the thing I am telling you about":

| | haber | + participle |
|---|---|---|
| yo | había | había comido |
| tú | habías | habías comido |
| él / Ud. | había | había comido |
| nosotros | habíamos | habíamos comido |
| vosotros | habíais | habíais comido |
| ellos / Uds. | habían | habían comido |

And the imperfect of `estar` builds the past continuous:

| | estar | + gerund |
|---|---|---|
| yo | estaba | estaba comiendo |
| tú | estabas | estabas comiendo |
| él / Ud. | estaba | estaba comiendo |
| nosotros | estábamos | estábamos comiendo |
| vosotros | estabais | estabais comiendo |
| ellos / Uds. | estaban | estaban comiendo |

## Set phrases that live in this tense

| | |
|---|---|
| **Había** una vez… | Once upon a time… |
| **Era** tarde. | It was late. |
| **Eran** las tres. | It was three o'clock. |
| **Hacía** frío. | It was cold. |
| Cuando **era** pequeño… | When I was little… |
| Mientras **veía** la tele… | While I was watching TV… |
| **Iba** a llamarte. | I was going to call you. |
| **Solía** ir los domingos. | I used to go on Sundays. |

Clock time, weather, age and description in the past take this tense automatically —
[imperfect vs preterite](imperfecto-vs-indefinido) is the page on when to choose it.
