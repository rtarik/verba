For something that might genuinely happen, Spanish keeps it simple:

> **si** + present + (future / present / imperative)

| | |
|---|---|
| `**Si apruebo**, invito a todos.` | present + present |
| `**Si apruebo**, invitaré a todos.` | present + future |
| `**Si llueve**, no salgas.` | present + command |

All three are correct. The present in the main clause sounds more immediate, almost like a
promise; the future is slightly more neutral.

## The one rule that matters

**Never put the future after `si`.**

- `**Si aprobaré**...` ✗
- `**Si apruebo**...` ✓

English has the same restriction — we say "if I pass", never "if I will pass" — so the instinct
is already there. It simply gets lost when learners start thinking about which Spanish tense
means "will".

The same goes for the conditional: `si aprobaría` is wrong too.

## Compare with cuando

`si` and `cuando` behave differently, and the contrast is worth holding onto:

| | |
|---|---|
| `**Cuando** apruebe, invito a todos.` | when I pass — I expect to |
| `**Si** apruebo, invito a todos.` | if I pass — it's genuinely open |

`cuando` about the future takes the **subjunctive** (Unit 13). `si` about the future takes the
**present indicative**. Two conjunctions, opposite requirements, and mixing them up is common.

## si also means "whether"

In a reported question, `si` is not a condition at all:

> `Me preguntó **si** quería cambiar de equipo.`

No condition, no future restriction — just "whether". Same word, different job.

## Watch out

This page is only about conditions that **could** happen. For ones that could not — `si tuviera
tiempo`, `si hubiera sabido` — Spanish switches to the past subjunctive, and those are the second
and third conditionals in B2 Units 18 and 20.
