Time conjunctions take **either** mood, and the choice is not about grammar so much as about
whether the event has happened.

> **Habitual or past → indicative. Still in the future → subjunctive.**

| | |
|---|---|
| `Siempre te llamo **cuando llego**.` | every time. It has happened often. |
| `**Cuando llegues**, llámame.` | one specific time, not yet real. |

English marks this with nothing at all — "when I arrive" covers both — which is why the
distinction takes so long to hear.

## The conjunctions this applies to

| | |
|---|---|
| **cuando** | when |
| **en cuanto** | as soon as |
| **hasta que** | until |
| **mientras** | while |
| **después de que** | after |
| **siempre que** | whenever |

All of them follow the same test:

- `**Mientras** estudiaba, mi hermana veía la tele.` — past, so indicative
- `**Mientras** espero los resultados, no voy a pensar.` — habitual now, indicative
- `Espera **hasta que salgan** las notas.` — not out yet, subjunctive

## antes de que is different

**`antes de que` always takes the subjunctive.** There is no choice, because whatever comes after
"before" has by definition not happened yet:

> `**Antes de que empiece** el verano, quiero reservar el vuelo.`

## One subject, no que

The Unit 11 rule holds here too. If the same person does both things, drop the `que` and use an
infinitive:

| | |
|---|---|
| `Antes de **salir**, revisé los correos.` | I check, I leave |
| `Antes de que **salgas**, llámame.` | I ask, you leave |

Same with `después de`: `después de **cenar**` versus `después de que **cenes**`.

## Watch out

Spanish never uses the future tense after these conjunctions, even though the meaning is clearly
future. `Cuando llegaré` is wrong; it must be `cuando llegue`. English does the same thing in
reverse — we say "when I arrive", not "when I will arrive" — so the instinct is already there.
