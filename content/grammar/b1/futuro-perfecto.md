The **future of `haber`** plus a participle. It says something will already be finished by a
point ahead of now.

> `Para cuando llegues, ya **habré terminado**.`

| | |
|---|---|
| yo | **habré** terminado |
| tú | **habrás** terminado |
| él / ella | **habrá** terminado |
| nosotros | **habremos** terminado |
| ellos | **habrán** terminado |

Note the sentence above combines three units: `cuando` + subjunctive (Unit 13), `ya` (Unit 5),
and this tense.

## The second job: guessing about the recent past

This is the use you will hear far more often, and it has nothing to do with the future.

| | |
|---|---|
| `Se **habrá dormido**.` | He'll have fallen asleep — *I assume* |
| `**Habrá perdido** el tren.` | He must have missed the train |
| `¿Qué **habrá pasado** aquí?` | What on earth happened here? |

You know nothing; you are speculating. English does the same thing with "will have" — *"he'll
have got lost"* — so the instinct exists, but Spanish reaches for it far more readily.

This mirrors the plain future's guessing use from Unit 9 (`Estará en casa`). The pattern is
consistent:

| | guess about now | guess about just now |
|---|---|---|
| | `Estará en casa.` | `Habrá llegado ya.` |

## Watch out

Because the guessing use is so common, context matters. `Habrá terminado a las nueve` could mean
"he will have finished by nine" or "he must have finished at nine". Spanish lets the situation
decide, and speakers rarely notice the ambiguity.
