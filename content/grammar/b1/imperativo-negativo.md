Unit 10 covered positive commands. The negative ones are built completely differently:

> **All negative commands use the subjunctive.**

| positive | negative |
|---|---|
| ¡Estudia! | ¡**No estudies**! |
| ¡Ven! | ¡**No vengas**! |
| ¡Bebe! | ¡**No bebas**! |
| ¡Haz! | ¡**No hagas**! |
| ¡Sal! | ¡**No salgas**! |

Notice that the eight irregular one-syllable commands — `sal`, `ven`, `haz`, `pon`, `di`, `ten`,
`ve`, `sé` — all disappear in the negative. Once there is a `no`, everything becomes regular
subjunctive, built from the `yo` form as usual.

## Which is a relief

There is no separate set of forms to learn. If you can produce `no creo que salgas`, you can
produce `no salgas` — it is the same word.

And it explains something you have been doing since Unit 10 without knowing: `No se preocupe`
was subjunctive all along.

## Pronouns move

This is the part that catches people. With a **positive** command the pronoun attaches to the
end; with a **negative** one it goes in front:

| | |
|---|---|
| `Llám**ame**.` | Call me |
| `**No me** llames.` | Don't call me |
| `Pon**telo**.` | Put it on |
| `**No te lo** pongas.` | Don't put it on |

The accent also disappears, because the word is no longer carrying an extra syllable.

## The full picture

| | tú | usted |
|---|---|---|
| positive | habla | hable |
| negative | no hables | no hable |

Three of those four cells are subjunctive. Only the positive `tú` command uses a form of its own —
which is why the imperative, taken as a whole, is mostly the subjunctive wearing a different hat.
