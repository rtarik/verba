Connectors are what turn a list of sentences into an argument. Spanish has a rich set, and using
them well is one of the clearest markers of a B1 speaker moving towards B2.

## Contrast

| | |
|---|---|
| **pero** | but — the everyday one |
| **sin embargo** | however — more formal |
| **en cambio** | on the other hand — direct comparison |
| **aunque** | although / even if — see [para que and aunque](para-que-aunque) |
| **por otro lado** | on the other hand — introducing a second angle |

`sin embargo` and `en cambio` are not interchangeable. `sin embargo` concedes something
unexpected; `en cambio` sets two things against each other.

## Consequence

| | |
|---|---|
| **por eso** | that's why — everyday |
| **por lo tanto** | therefore — formal |
| **así que** | so — spoken |
| **entonces** | then, so |

## Adding

| | |
|---|---|
| **además** | besides, moreover |
| **también** | also |
| **encima** | on top of that — often negative |

## Explaining and correcting

| | |
|---|---|
| **es decir** | that is to say |
| **o sea** | in other words — very common in speech |
| **de hecho** | in fact |
| **sino** | but rather |

**sino** is worth care: it corrects a negative, where `pero` merely adds a contrast.

- `No es difícil, **pero** es largo.` — two facts
- `No se aprende por partes, **sino** todo a la vez.` — correcting the first half

## Ordering

**primero**, **luego**, **después**, **por último**, **en primer lugar**, **finalmente**.

## Watch out

The commonest mistake is using too many. A connector earns its place by making a relationship
explicit that the reader would otherwise have to work out. Three in a paragraph is usually plenty;
five in a row hide the argument rather than revealing it.

Spanish prose does use them more freely than English prose, but the limit still exists.
