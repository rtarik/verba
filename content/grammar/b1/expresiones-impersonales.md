The most productive pattern in the whole subjunctive system:

> **es + adjective + que + subjunctive**

Learn the frame once and every adjective you know slots into it.

| | |
|---|---|
| Es importante que | `practiques todos los días` |
| Es necesario que | `entiendas lo esencial` |
| Es mejor que | `leas textos completos` |
| Es normal que | `te equivoques` |
| Es raro que | `alguien no se equivoque` |
| Es posible que | `venga` |
| Es lógico que | `un idioma marque esa diferencia` |
| Es una pena que | `la gente abandone` |

Nouns work in the frame too: `es una pena que`, `es una lástima que`, `es hora de que`.

## The exception: expressions of certainty

If the expression asserts that something **is true**, it takes the indicative instead:

| certainty → indicative | everything else → subjunctive |
|---|---|
| Es verdad que **viene**. | Es posible que **venga**. |
| Es evidente que **puede**. | Es raro que **pueda**. |
| Está claro que **sabe**. | Es dudoso que **sepa**. |
| Es seguro que **llega**. | Es probable que **llegue**. |

And as always, negating them flips the mood back: `No es verdad que **venga**`.

The logic is consistent with everything in this unit — certainty is indicative, and anything
short of certainty is subjunctive. `Es probable` sounds confident in English, but "probable" is
not "certain", so Spanish files it under doubt.

## When nobody in particular is meant

If the advice is general rather than aimed at a person, drop the `que` and use an infinitive:

| | |
|---|---|
| `Es importante **practicar**.` | It's important to practise — in general |
| `Es importante que **practiques**.` | It's important that **you** practise |

This is the same one-subject/two-subject test from Unit 11, wearing a different hat.
