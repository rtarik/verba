Everything you have learned so far has been the **indicative** — the mood for stating what is.
The subjunctive is a different mood, for what is wanted, hoped for, doubted or asked. It is not
a tense: it has its own present, its own past, and it sits alongside everything you already know.

English lost almost all of its subjunctive, keeping only fossils like *"I insist that he **be**
present"*. Spanish uses it constantly.

## How to build it

Start from the **yo form of the present indicative**, drop the `-o`, and add the *opposite*
vowel:

| infinitive | yo form | subjunctive |
|---|---|---|
| hablar | habl**o** | habl**e** |
| comer | com**o** | com**a** |
| vivir | viv**o** | viv**a** |

**-ar verbs take e. -er and -ir verbs take a.** The endings swap over, which is why the
subjunctive so often looks like "the wrong verb".

| | hablar | comer |
|---|---|---|
| yo | habl**e** | com**a** |
| tú | habl**es** | com**as** |
| él / ella | habl**e** | com**a** |
| nosotros | habl**emos** | com**amos** |
| ellos | habl**en** | com**an** |

## Why the yo form matters

Because any irregularity in `yo` carries straight through:

| | yo form | subjunctive |
|---|---|---|
| tener | ten**go** | **tenga** |
| salir | sal**go** | **salga** |
| hacer | ha**go** | **haga** |
| decir | di**go** | **diga** |
| venir | ven**go** | **venga** |
| conocer | cono**zco** | **conozca** |

So these are not extra irregulars to learn — they are the ones you already know, behaving
consistently.

## The six that are genuinely irregular

| | |
|---|---|
| ser | **sea** |
| estar | **esté** |
| ir | **vaya** |
| saber | **sepa** |
| haber | **haya** |
| dar | **dé** |

That is the whole list. Note `esté` and `dé` carry accents to distinguish them from `este`
(this) and `de` (of).

## You have already been using it

The polite commands from Unit 10 — `Salga por esa puerta`, `No se preocupe`, `Tome el autobús` —
are subjunctive forms. You have been reading them for a unit without needing the name.

What triggers it is the subject of [wanting, hoping, asking](subjuntivo-deseos).
