The **conditional of `haber`** plus a participle. For a past that never happened.

> `Yo **habría hecho** lo mismo.`

| | |
|---|---|
| yo | **habría** hecho |
| tú | **habrías** hecho |
| él / ella | **habría** hecho |
| nosotros | **habríamos** hecho |
| ellos | **habrían** hecho |

If you know the conditional from Unit 9, this is that tense applied to `haber`. Nothing new to
memorise.

## What it is for

**Hindsight** — what you would have done, given the chance:

> `Yo **habría aguantado**. **Habría dicho** que no pasa nada y **habría vuelto** a casa el domingo.`

**Regret** — the same thing, with feeling:

> `**Habría dado** cualquier cosa por entenderlo entonces.`

**Guessing about a more distant past**, completing the set:

> `**Habrían salido** ya cuando llamaste.` — they must have already left.

## The three compound tenses side by side

All three are `haber` + participle. Only the tense of `haber` changes, and it changes the whole
meaning:

| | |
|---|---|
| `**había** terminado` | I had finished — before another past event |
| `**habré** terminado` | I will have finished — before a future point |
| `**habría** terminado` | I would have finished — but I didn't |

Once you see them as one construction with three settings, the set stops feeling like three
separate tenses to learn.

## Watch out

This tense is the natural home of the **third conditional** — `si hubiera sabido, habría
venido` — which needs the pluperfect subjunctive in the other half. That waits until Unit 18.
For now, `habría` works perfectly well on its own, with the condition left unstated or implied.

Also note the difference from the plain conditional:

| | |
|---|---|
| `**Iría** contigo.` | I would go — the offer is still open |
| `**Habría ido** contigo.` | I would have gone — too late now |
